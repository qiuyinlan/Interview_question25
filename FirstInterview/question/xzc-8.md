### 8.指针！数组！

尝试解释一下下列语句吧～

```c
int main () {
int a[ 3 ] = { 2 ，4 , 8 };
int(*b)[ 3 ] = &a;
int *c[ 3 ] = {a, a + 1， a + 2 };
int (*f1(int))(int*, int);
return 0 ;
}
```
说说下列输出分别是什么？
```c
a,*b, *b + 1 , b, b + 1 , *(*b + 1 ),c
sizeof(a),sizeof(b)，sizeof(&a)

```

Q1.解释指针数组，数组指针，函数指针 40%

Q2.讲讲数组名衰变 35%

Q3.sizeof特性 25%

```
A1：
答案--64位系统下：
a: 0x7ffea81d4cb4
*b: 0x7ffea81d4cb4
*b + 1: 0x7ffea81d4cb8
b: 0x7ffea81d4cb4
b + 1: 0x7ffea81d4cc0
*(*b + 1): 4
c: 0x7ffea81d4cc0
sizeof(a): 12
sizeof(b): 8
sizeof(&a): 8


a: 0x7ffea81d4cb4

a 在表达式里衰变成 &a[0]。

指向第一个元素 2，所以地址就是数组开头。

*b: 0x7ffea81d4cb4

b 是“指向整个数组的指针”，即 b = &a。

*b 解引用以后，就是 a。

所以 *b 的值也是 0x7ffea81d4cb4。
👉 这说明 *b == a。

*b + 1: 0x7ffea81d4cb8

*b = a = 0x7ffea81d4cb4。

*b + 1 = a + 1，就是跳过一个 int（4字节）。

所以地址 0x7ffea81d4cb4 + 4 = 0x7ffea81d4cb8。
👉 正好指向 a[1] 的位置。

b: 0x7ffea81d4cb4

b = &a，指向整个数组。

对于数组 a[3] 来说，&a 的值就是数组开头的地址。

b + 1: 0x7ffea81d4cc0

注意 ⚠️：b 的类型是 int (*)[3]（指向3个int的数组）。

所以 b+1 会跳过 整个数组 a。

数组 a 的大小是 3*4 = 12 字节。

0x7ffea81d4cb4 + 12 = 0x7ffea81d4cc0。
👉 这就是 b+1 的地址。

*(*b + 1): 4

*b = a。

*b + 1 = a+1 → 指向第二个元素。

*(*b+1) = *(a+1) = a[1] = 4。
👉 输出 4。

c: 0x7ffea81d4c0...

c 是 指针数组，类型是 int *[3]。

它的元素分别存的是：a, a+1, a+2。

在内存里，c[0]、c[1]、c[2] 各占 8 字节（指针大小）。

所以 c 自身的起始地址和 a 是完全不一样的（因为 c 是另一个数组）。



a 衰变 → 地址 &a[0]
*b 解引用 → 数组 a → 衰变 → 地址 &a[0]
b → 数组 a 的地址 &a

数组指针是指向数组的指针，本质是指针
指针数组是里面元素都是指针的数组,本质是数组
函数指针是指向函数的指针,本质是指针

f1(int) → 说明 f1 本身是一个函数，它的 参数是一个 int。

(*f1(int)) → f1 返回一个 指针。

(*f1(int))(int*, int) → 这个指针指向一个函数，而这个函数的参数是 int* 和 int。

最外层的 int → 说明这个函数的返回值是 int。


A2：
在 C 语言里，数组名在大多数表达式中会“衰变”成一个指向数组首元素的指针。
不会衰变的特殊情况有 三种：
1. 数组名作为函数参数时
2. 数组名作为 sizeof 运算符的操作数时
3. 数组名作为 & 运算符的操作数时

A3：
sizeof(数组) 给出数组实际大小。
sizeof(指针) 给出指针大小（通常 4 或 8）。
```
